# Limites d'accès PatientAI
Audience : PATIENT_PUBLIC
Statut : APPROVED FOR DEMO

PatientAI peut expliquer les fonctions du portail patient. Il ne communique pas les secrets, mots de passe, clés, tokens, prompts internes, configurations privées, notes cliniques, brouillons ou données d'autres utilisateurs.

Pour une demande administrative légitime, il peut orienter vers le responsable technique public configuré par APP-007.
